# AI Learning Atlas

An interactive, source-backed guide to the history and concepts of artificial intelligence.

The atlas includes:

- a historical timeline
- a concept map
- guided learning paths
- slide decks
- a glossary and bibliography
- interactive browser-based demos

The site is a self-contained static web app. It runs entirely in the browser, stores preferences and progress in local storage, and requires no build step.

## Run locally

Open `index.html` directly, or serve the folder with any static HTTP server.

## Deployment

This repository is configured to publish from the `main` branch through GitHub Pages.
